# Parity ledger — sub-project 4a

ADK-Go commit: see `docs/parity/ADK_GO_COMMIT`. Test-name rule: see the 1b spec § Parity tooling.

Rows below the table header are generated by `python3 scripts/parity-check --ledger 4a --generate`
from annotations in each Go test file's Rust target. Do not edit rows by hand:
- `fn test_foo` in the target → `ported`; a `// parity: adapted: <reason>` line within the 3
  lines above the `fn` → `ported (adapted: <reason>)`;
- a line `// parity: skipped TestFoo: <reason>` in the target → `skipped`.

Targets: `session/database/service_test.go` →
`crates/gadk-session-database/tests/session_database_service.rs`; `session/database/session_test.go`
→ `crates/gadk-session-database/src/parity_tests/session_database_session.rs` (the tests reach the
crate-private session type); `session/database/compaction_test.go` →
`crates/gadk-engine/src/parity_tests/session_database_compaction.rs` (it needs gadk-engine's
crate-private compaction repair). The 3 files hold 15 `Test*` functions.

Accepted divergences (each annotated where it lives):
- `DatabaseSessionService::connect` takes a database URL (`sqlite:`, `postgres:`) where Go takes
  a `gorm.Dialector` plus `gorm.Option`s; `from_sqlite_pool` / `from_pg_pool` replace
  `NewSessionServiceFromDB`, so Go's nil-`*gorm.DB` error has no counterpart;
- `auto_migrate` creates missing tables and adds missing columns but never alters an existing
  column's type, size or nullability, as gorm's `AutoMigrate` may;
- sqlite timestamps are always written in UTC (`…+00:00`); ADK-Go writes the time's own offset,
  so the text differs (never the instant) when Go runs outside UTC; the stale-session error
  renders its times in UTC where Go uses the local zone;
- a storage error's cause is sqlx's or serde_json's wording after Go's exact prefix
  (`failed to save event: …`);
- the PostgreSQL DDL follows gorm's postgres type mapping but is not compared with Go (ADK-Go
  has no gorm postgres driver in its module);
- gadk state is a `serde_json` map, which cannot hold NaN, so Go's non-JSON-state test is
  skipped.
