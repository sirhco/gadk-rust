# Parity ledger — sub-project 6

ADK-Go commit: see `docs/parity/ADK_GO_COMMIT`. Test-name rule: see the 1b spec § Parity tooling.

Rows below the table header are generated by `python3 scripts/parity-check --ledger 6 --generate`
from annotations in each Go test file's Rust target. Do not edit rows by hand:
- `fn test_foo` in the target → `ported`; a `// parity: adapted: <reason>` line within the 3
  lines above the `fn` → `ported (adapted: <reason>)`;
- a line `// parity: skipped TestFoo: <reason>` in the target → `skipped`.

Targets follow `target_name` (`cmd/launcher/web/api/api_test.go` → `cmd_launcher_web_api_api.rs`)
and all live in `crates/gadk-launcher`: tests that reach crate-private code (the console and its
HITL prompting, the web router and server, the sub-launchers' setup, triggerauth, the telemetry
builder) live in `crates/gadk-launcher/src/parity_tests/`; tests of public API only
(`launcher_validate_test.go`, `full_test.go`) in `crates/gadk-launcher/tests/`. The Go `flag` and
`time.ParseDuration`/`Duration.String` ports (`gadk_platform::go_flag`, `go_parse_duration`,
`go_format_duration`) are tested in `gadk-platform` from Go's standard-library tests and have no
rows here. The wire, console and CLI fixtures recorded by `scripts/gen-go-launcher` are replayed by
`crates/gadk-launcher/tests/wire_replay.rs`; each declared delta cites a divergence below.

Out of scope (not ported):
- `cmd/adkgo` and `cmd/internal/adkcli` (the deploy tool, sub-project 6b), with
  `internal/cli/util/text_helpers.go` and `oscmd.go`, which only they use: the 4
  `text_helpers_test.go` tests are skipped with that reason; the `cmd/adkgo` test files are listed
  in the deferred block below so the tool checks they stay out of the in-scope list;
- the Agent Engine launchers and routes (`cmd/launcher/agentengine`,
  `cmd/launcher/web/agentengine`; sub-project 5c);
- the A2A 0.3 compatibility endpoint `/a2a/invoke` and the 0.3 fields of the agent card (a2a-rs
  implements A2A v1 only);
- OpenTelemetry providers, cloud export and metrics (sub-project 7);
- building the ADK web UI from source (the google/adk-web bundle is vendored byte for byte).

Accepted divergences (each annotated where it lives):

- The A2A 0.3 endpoint (`/a2a/invoke`, gorilla's 404) and the agent card's 0.3 union fields are absent.
- `-otel_to_cloud` fails `Run` with `telemetry initialization failed: -otel_to_cloud requires OpenTelemetry export, which gadk adds in sub-project 7`; `Config.telemetry_layers` (Go `TelemetryOptions`) are `tracing` layers, so no option turns cloud export on.
- An existing global `tracing` subscriber is kept and the launcher logs that its telemetry layers were not installed (Go always replaces the global OpenTelemetry providers).
- tokio's Ctrl-C handler stays installed after the console's `run` returns (Go's `signal.NotifyContext` stop restores the default).
- Go `a2asrv.RequestHandlerOption`s with no a2a-rs equivalent cannot be expressed as `A2AHandlerHook`s.
- HTTP timeout semantics where hyper differs from `net/http` (`-read-timeout`, `-write-timeout`, `-idle-timeout`).
- Only Go's built-in MIME table is used (Go also reads the host's MIME files).
- The web launcher prints the sub-launchers' `UserMessage` lines in declaration order (Go iterates a map).
- Status texts and headers that come from hyper or a2a-rs rather than Go (each named by a replay delta).
- Go `flag` panics on a flag name that starts with `-`, contains `=` or is defined twice; `gadk_platform::go_flag` writes Go's message line and ignores the definition (launcher flag names are static, so this never fires).
