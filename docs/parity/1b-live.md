# Parity ledger — sub-project 1b-live

ADK-Go commit: see `docs/parity/ADK_GO_COMMIT`. Test-name rule: see the 1b spec § Parity tooling.

Rows below the table header are generated by `python3 scripts/parity-check --ledger 1b-live --generate`
from annotations in each Go test file's Rust target (`crates/*/tests/<target>.rs` or
`crates/*/src/parity_tests/<target>.rs`, where `<target>` is the Go path without `_test.go`, with `/`
replaced by `_`). Do not edit rows by hand:
- `fn test_foo` in the target → `ported`; a `// parity: adapted: <reason>` line within the 3 lines
  above the `fn` → `ported (adapted: <reason>)`;
- a line `// parity: skipped TestFoo: <reason>` in the target → `skipped`.

The live tests of 1b's own files (the five `TestSequentialAgent_RunLive_*` tests, `TestIsResumable*`,
the streaming-tool live tests, `TestCancelledToolContextKeepsIdentity` and
`TestInvocationContext_LiveSessionResumptionHandle`) keep their rows in `docs/parity/1b.md`.

The `task_completed` injection permanently adds the tool and the instruction suffix to every LLM
sub-agent of a `SequentialAgent` that has run live, so the agent's later non-live requests change
too. This is ADK-Go behaviour (`agent/workflowagents/sequentialagent/agent.go`), kept on purpose.
