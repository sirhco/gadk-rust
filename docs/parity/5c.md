# Parity ledger — sub-project 5c

ADK-Go commit: see `docs/parity/ADK_GO_COMMIT`. Test-name rule: see the 1b spec § Parity tooling.

Rows below the table header are generated by `python3 scripts/parity-check --ledger 5c --generate`
from annotations in each Go test file's Rust target. Do not edit rows by hand:
- `fn test_foo` in the target → `ported`; a `// parity: adapted: <reason>` line within the 3
  lines above the `fn` → `ported (adapted: <reason>)`;
- a line `// parity: skipped TestFoo: <reason>` in the target → `skipped`.

Targets follow `target_name` (`server/agentengine/handler_test.go` →
`server_agentengine_handler.rs`) and are in-crate modules, because they reach crate-private code:
the `server/agentengine` ports live in `crates/gadk-server/src/parity_tests/` (feature
`agentengine`), the `agentregistry` ports in `crates/gadk-agentregistry/src/parity_tests/` (the
factory port needs features `a2a` and `mcp`, the e2e ports one each).

Beyond the ports, the wire fixtures `scripts/gen-go-agentengine` records from ADK-Go's real
handler and launcher are replayed byte for byte: the 29 server fixtures
(`crates/gadk-server/testdata/agentengine/`) in order through `new_handler`
(`agentengine::method::replay`), the 13 launcher fixtures (`crates/gadk-launcher/testdata/agentengine/`)
through the `agentengine` sub-launcher and the web server (`web::agentengine` tests); no fixture
declares a delta. `crates/gadk-launcher/tests/agentengine_e2e.rs` runs `new_launcher` end to end
and checks the real server cuts a stream at the `-sse-write-timeout` deadline. The
`ConvertSnake` shape table (`encode_shapes.rs`) is generated by the probe from Go reflection and
verified by `scripts/check-fixtures.sh`.

Go's `cmd/launcher/agentengine` and `cmd/launcher/web/agentengine` have no test files; their
behaviour is covered by the launcher fixtures above. Out of scope (not ported): the Agent Engine
deploy tool (`cmd/adkgo`, sub-project 6b).

Accepted divergences (each annotated where it lives):

Agent Engine server (`gadk_server::agentengine`):
- The `Processing event: %+v err: %+v` log line is written with Rust's `Debug` of the event and
  `<nil>` (Go's `%+v` struct dump); the fixtures and the replay drop these lines.
- The `Failed to convert: …` line of a value `ConvertSnake` cannot walk uses Rust's `Debug` and
  type name (Go `%+v` / `%T`), and an embedded struct that fails to encode reports serde_json's
  text; neither is reachable with gadk's types.
- Request JSON (`go_unmarshal`): syntax errors other than truncated input keep serde_json's
  wording after Go's prefix (as in 5a); a lone surrogate or invalid UTF-8 in a string is
  rejected (Go replaces it with U+FFFD); a `null` element of `parts` fails gadk-genai's decode
  (Go keeps a nil part); the error texts of `genai.Transcription`'s and `VideoMetadata`'s
  duration fields are not Go's.
- An event timestamp outside the years 0–9999 cannot be serialized by gadk (Go writes its
  seconds).
- `SetWriteDeadline failed: feature not supported` is logged when a request carries no
  `gadk_server::mux::WriteDeadline` hook (Go: when the `ResponseWriter` cannot set deadlines);
  every gadk server inserts the hook, so it is only unit-tested.
- The stream loops have no counterpart of Go's nil-event check (gadk's event stream yields no
  nil events) or of an `EmitJSON` write error when the client is gone (the server writes the
  body; a failed write ends the connection).
- `AgentEngineConfig` requires an agent loader (Go's `launcher.Config` may have none), and
  `new_handler` leaves Go's `config.Validate()` to its caller (the launcher runs
  `Config::validate` first, with the same text); `ListClassMethods` returns the metadata maps
  (`Vec<Map<String, Value>>`), not `*structpb.Struct`s.
- The duplicate-method wrap (`controllers.NewAgentEngineAPIController failed (for …): duplicate
  method name: …`) and `ensureBackendSession`'s `session service is required` are unreachable,
  as in Go's handler.
- Request bodies are capped at 512 levels of nesting (`unmarshal::MAX_DEPTH`; Go's
  `encoding/json` allows 10000), with Go's counting rule, error text (`exceeded max depth`) and
  400. This is a temporary cap: past the server, gadk-engine's runner, `gadk_model::to_go_json`
  and the session service clone, convert and drop a request's message or session state
  recursively, which overflows a 2 MiB stack in a debug build at about 900–1100 levels; it is
  lifted to Go's 10000 once those paths are depth-safe.
- A `json.RawMessage` field (`GoKind::RawMessage`) is decoded with serde_json's 128-level depth
  limit and its error text (Go's max depth is 10000); no request shape has such a field.
- Input deeper than 64 levels is decoded on a 64 MiB thread; when that thread cannot be spawned
  or panics, the answer is 500 `agentengine: deep-input decoder unavailable: …` (no Go
  counterpart: Go's stacks grow).
- The stream methods encode each runner item on that deep stack; when the thread cannot be
  spawned the item is leaked and `helper.EmitJSON() failed: agentengine: deep-stack thread
  unavailable: …` is logged, and when it panics the item is dropped there and `… deep-stack
  thread failed: the thread panicked` is logged; neither line has a Go counterpart.
- The `ConvertSnake` encoder reads serde's `to_value` output, where a NaN or ±Inf float is
  already `null`: it is written as `0` (a pointer to it is nil, then dropped). Go fails the
  encode with `json: unsupported value: NaN` and logs the error line.
- A `json.RawMessage` value (e.g. a jsonschema `Default`) is re-serialised from serde's `Value`:
  keys sorted, number text normalised (Go keeps the author's compacted text).

Agent Engine launcher (`gadk_launcher::web::agentengine`):
- `setup_subrouters` without a session service (never the case through `Run`, which fills every
  service first) fails with `agentengine.NewHandler failed: no session service configured` (Go
  passes the nil service on).

Agent Registry (`gadk-agentregistry`):
- No mTLS client certificate: with `GOOGLE_API_USE_MTLS_ENDPOINT=auto` (or unset) the standard
  endpoint is used even when a client certificate is configured, and `always` with a non-default
  universe domain is not an error (Go `cba.go`).
- With `HOME` unset no well-known ADC file is read (Go finds it through `user.Current()`).
- Transport, decode and credential errors carry reqwest's, serde_json's and gadk-auth's texts
  after Go's prefixes; registry JSON, the ADC credentials JSON's `quota_project_id` and the
  embedded agent card (`decode_card`) are decoded case-sensitively (Go's `encoding/json` matches
  field names case-insensitively); the embedded agent card's decode errors keep serde's text.
- Request URLs are parsed by `reqwest::Url::parse`, which normalises `.` / `..` path segments
  and accepts an invalid escape such as `%zz`; Go's `url.Parse` + `RequestURI()` sends
  `projects/p/../x` as written and fails `%zz` with `building request:`.
- An embedded card whose `supportedInterfaces` is `[null]` fails at `remote_agent` with `has no
  supported interfaces` (Go builds the agent and fails only when it is invoked).
- Default request headers (`User-Agent`, `Accept-Encoding`) are reqwest's, not Go's.
- Egress is an `EgressClient` choice (`Option`, `Registry`, `Default`) plus a header list
  instead of distinct `*http.Client` values; Go's client-identity tests are ported as assertions
  on that choice. A2A headers are sent by a `CallInterceptor` as service parameters; MCP headers
  go in `McpTransport::StreamableHttp.headers`, where a value that is not a valid header is
  skipped. a2a-client-lf appends the A2A service parameters with reqwest's `builder.header`, so a
  header its transport also sets (e.g. `Accept`) is sent with two values (Go's `Header.Set`
  replaces it), and a value reqwest rejects fails the A2A request (MCP skips it; Go sends it).
- A2A 0.x agents are reached by rewriting the card's 0.x `JSONRPC` / `HTTP+JSON` interfaces to
  the current protocol version in gadk's `CompatClientProvider` (Go registers compat transports
  with `WithCompatTransport`); an a2a-rs API for version-keyed transport registration would
  remove the rewrite.
