## Deliberate deviations from ADK-Go

- Vertex AI never accepts an API key (express mode is rejected); auth is ADC or explicit google-cloud-auth credentials only.
- The tracking headers `user-agent` and `x-goog-api-client` are space-joined with any pre-existing value; ADK-Go replaces `user-agent`.
- `TestModel_TrackingHeaders` `vertex_enabled` uses project/location plus credentials instead of express mode.
- `LiveConnection::recv` returns `None` on a closed connection.
- Task timestamps, durations and int64 JSON quirks are value-equal but not byte-equal in a few places (e.g. `.500Z` vs `.5Z` in genai types).
