# Parity ledger — sub-project 5b

ADK-Go commit: see `docs/parity/ADK_GO_COMMIT`. Test-name rule: see the 1b spec § Parity tooling.

Rows below the table header are generated by `python3 scripts/parity-check --ledger 5b --generate`
from annotations in each Go test file's Rust target. Do not edit rows by hand:
- `fn test_foo` in the target → `ported`; a `// parity: adapted: <reason>` line within the 3
  lines above the `fn` → `ported (adapted: <reason>)`;
- a line `// parity: skipped TestFoo: <reason>` in the target → `skipped`.

Targets follow `target_name` (`server/adka2a/v2/parts_test.go` → `server_adka2a_v2_parts.rs`):
tests that reach crate-private code (metadata helpers, the executor and its processor, the remote
agent's run loop, run processor and history, the auth core, child-task cancellation) live in
`crates/gadk-a2a/src/parity_tests/`; tests of public API only in `crates/gadk-a2a/tests/`.
`agent/remoteagent/v2/auth_test.go` is the in-crate module directory
`crates/gadk-a2a/src/parity_tests/agent_remoteagent_v2_auth/`: `transport.rs` holds the
transport-level tests (mint groups, HTTP clients, redirects, redaction, cleartext detection,
credential application), `agent.rs` the tests that run an agent through `new_a2a`.
`server/adka2a/v2/example_test.go` holds only an `Example` (no `Test*`), so it has no rows; it is
ported as the doc example on `server::Executor`.

Out of scope (not ported):
- the Go-deprecated A2A v1 integration: `server/adka2a` (v1), `agent/remoteagent/a2a_agent.go`
  and its test `agent/remoteagent/a2a_agent_compat_test.go` (listed in the deferred block below so
  the tool checks it stays out of the in-scope list), and `a2acompat/a2av0`;
- gRPC, SLIMRPC and protobuf bindings;
- `agentregistry` (sub-project 5b-registry), `cmd/launcher/web/a2a` (sub-project 6),
  `server/agentengine` (sub-project 5c);
- an A2A request handler or task store of gadk's own (a2a-rs `DefaultRequestHandler` and
  `InMemoryTaskStore` are used as they are).
