# Parity ledger — sub-project 3b

ADK-Go commit: see `docs/parity/ADK_GO_COMMIT`. Test-name rule: see the 1b spec § Parity tooling.

Rows below the table header are generated by `python3 scripts/parity-check --ledger 3b --generate`
from annotations in each Go test file's Rust target. Do not edit rows by hand:
- `fn test_foo` (or `fn fuzz_foo`) in the target → `ported`; a `// parity: adapted: <reason>` line
  within the 3 lines above the `fn` → `ported (adapted: <reason>)`;
- a line `// parity: skipped TestFoo: <reason>` in the target → `skipped`.

`model/openaimodel/openaimodel_test.go`'s target is
`crates/gadk-openai/tests/model_openaimodel_openaimodel.rs`. Each
`model/openaimodel/internal/<pkg>/<f>_test.go` is ported inside the crate (the tests reach
package-private code), in `crates/gadk-openai/src/parity_tests/model_openaimodel_internal_<pkg>_<f>.rs`,
except `internal/responses/request_test.go` and `internal/responses/model_test.go`, whose targets
are the module directories `crates/gadk-openai/src/parity_tests/model_openaimodel_internal_responses_request/`
and `crates/gadk-openai/src/parity_tests/model_openaimodel_internal_responses_model/` (`mod.rs`
and one module per group of tests); a row's Rust file is the file that holds the `fn` or the
skip line. The 19 files hold 215 `Test*` and 2 `Fuzz*` functions (217 rows).

Accepted divergences (each annotated where it lives):
- the `User-Agent` is gadk's `gadk_platform::tracking_header()`, not openai-go's
  `OpenAI/Go 3.82.0`; the SDK's `X-Stainless-*` headers are not sent;
- Go's `ClientConfig.Options` (`[]option.RequestOption`, including `WithMiddleware`), the admin
  API key and the webhook secret are not ported: `ClientConfig.headers` and
  `ClientConfig.http_client` cover the options ADK-Go's tests use;
- openai-go's credential-origin redirect guard has no counterpart: gadk's `ReqwestClient` uses
  reqwest's redirect policy, which drops `Authorization` when a redirect leaves the host;
- `ClientConfig.api` is an enum, so Go's `NewModel` rejecting an unknown `API` value becomes
  `Api::from_str` failing with the same text (`openai: unsupported API: "<v>"`);
- cancellation is by dropping the response stream (`LlmRequest` carries no context): Go's
  cancelled-context subtests are adapted;
- retry jitter uses `rand`; tests assert bounds, as Go's do;
- a transport error's text is the cause without Go's `Post "<url>": ` prefix (no URL reaches an
  error), and a scheme-less base URL fails without the SDK's retries;
- serde_json's wording replaces Go `encoding/json`'s, except where a Go test asserts the text:
  a truncated event is `unexpected end of JSON input`, a truncated or empty blocking body
  `error parsing response json: unexpected EOF` / `…: EOF`;
- response decoding follows openai-go `apijson`'s leniency for the shapes ADK-Go reads (a
  missing, `null` or wrongly typed field is its zero value; a scalar in a string field is its raw
  text; an integer field takes a float or numeric string), not every coercion `apijson` makes;
- JSON numbers that do not fit an `f64` (`1e400`) in a schema or in arguments cannot be kept as
  written (serde_json without `arbitrary_precision`);
- Go's `nil` and empty maps and slices in genai values are one value in gadk (`labels`,
  `safety_settings`, `FunctionResponse.response`): presence checks read "non-empty";
- the SSE parser is gadk-model's (3a's divergences: an event with a name but no data is skipped,
  a final event without a trailing blank line is emitted).
