# Parity ledger — sub-project 4c

ADK-Go commit: see `docs/parity/ADK_GO_COMMIT`. Test-name rule: see the 1b spec § Parity tooling.

Rows below the table header are generated by `python3 scripts/parity-check --ledger 4c --generate`
from annotations in each Go test file's Rust target. Do not edit rows by hand:
- `fn test_foo` in the target → `ported`; a `// parity: adapted: <reason>` line within the 3
  lines above the `fn` → `ported (adapted: <reason>)`;
- a line `// parity: skipped TestFoo: <reason>` in the target → `skipped`.

Targets: `session/vertexai/X_test.go` →
`crates/gadk-vertexai/src/parity_tests/session_vertexai_X.rs`, except `vertexai_test.go` → the
module directory `crates/gadk-vertexai/src/parity_tests/session_vertexai_vertexai/` (`convert.rs`
holds the conversion tests, `client.rs` the client tests). All reach the crate-private client,
conversions and test servers (`ReplayServer` on the 22 fixtures in
`crates/gadk-vertexai/testdata/replays/`, `FakeAgentEngine`), both on a 127.0.0.1 fake server.
The 9 files hold 35 `Test*` functions. `TestAiplatformToGenaiContentPreservesFunctionIDs` ports
as `test_aiplatform_to_genai_content_preserves_function_i_ds` (the name rule splits `IDs`).

Accepted divergences (each annotated where it lives):
- the Vertex AI `v1beta1` REST/JSON API instead of gRPC: the fixtures are converted from Go's gRPC
  recordings, and requests are compared with them as protobuf values;
- `SessionError::NotFound` drops Go's `"%q: …"` not-found detail;
- memory's state time key is read as an RFC 3339 string, not a Go `time.Time`;
- memory's operation done without a result is plain success (Go matches the error string
  `unsupported result type <nil>: <nil>`);
- the append type error names `another Session implementation` where Go prints `%T`;
- `InvalidRequest` errors display with gadk's `invalid request: ` prefix before Go's text;
- `Test_vertexaiService_AppendEvent_StructuralValidation`'s `nil_event` subcase is N/A (an
  `&mut Event` cannot be null); its `missing_author` / `missing_invocation_id` subcases run on
  `FakeAgentEngine` instead of recordings that never match;
- delete's and create's `context` cancellation is dropping the future;
- `VertexAiSessionService::new` returns `SessionError` and `VertexAiMemoryService::new` returns
  `MemoryError` (`Backend`, Go's wrapper texts `failed to create Vertex AI client: could not
  establish connection to the aiplatform server: …` and `newVertexAIClient failed:
  aiplatform.NewMemoryBankClient failed: …`), not a `VertexError`.
