Accepted divergences (each annotated where it lives):
- the `User-Agent` on the Anthropic backend is gadk's `gadk_platform::tracking_header()`, not
  the SDK's `Anthropic/Go 1.81.0` (scrubbed in replay); on Vertex, `x-goog-api-client` and `user-agent`
  carry the same tracking value rather than `google-adk/<version> gl-go/<go version>`;
- the SDK's `X-Stainless-*` headers are not sent;
- Go's `ClientConfig.RequestOptions`, `TokenSource` and `Logger` are not ported: their subtests
  are adapted to `base_url`, `headers`, `http_client`, `credentials` and `tracing`, or skipped
  with a reason;
- `MaxTokens`, `MaxRetries` and `HTTPOptions.Timeout` are unsigned (`u32`, `Duration`), so Go's
  negative-value subtests are adapted;
- retry jitter uses `rand`; tests assert bounds, as Go's do;
- cancellation is by dropping the response stream (`LlmRequest` carries no context): Go's
  cancelled-context subtests are adapted;
- `tracing` events replace Go's `slog` warnings;
- with several extra keys in a tool's `input_schema`, gadk writes them sorted; the SDK appends
  them in Go map order (random);
- invalid UTF-8 in a thought signature or in `text/plain` inline data becomes one U+FFFD per
  invalid byte, as in Go, but gadk writes it as the raw UTF-8 character where the SDK's encoder
  writes the escape `\ufffd` (same JSON value, different bytes);
- the SSE parser skips an event that has a name but no data (Go dispatches it: an empty-data
  `event: error` becomes an `APIError`, another named event fails to decode) and emits a final
  event that is not followed by a blank line (Go's scanner drops it); invalid UTF-8 in a
  `data:` or `event:` value fails the stream (Go's JSON decoder substitutes U+FFFD in data, and
  an event name that is not valid UTF-8 matches no event type);
- the streaming tool-input refresh checks JSON validity with serde_json, whose recursion limit
  is 128; Go's `json.Valid` allows 10000 levels, so valid input nested deeper than 128 is
  replaced by `{}` where Go keeps it;
- `validate_base_url` rejects a port above 65535 (the `url` crate's parser); Go's `url.Parse`
  accepts any digits;
- Go `classifyError`'s fallback that decodes an error envelope from an error's text has no
  counterpart: gadk classifies a mid-stream `error` event directly from its JSON;
- a Vertex `base_url` with its own path (`https://proxy.example/vertex`) gets
  `{base_url}/v1/messages` with `model` kept in the body and `anthropic_version` appended, as the
  SDK's Vertex middleware does (it rewrites only the exact path `/v1/messages`); the 3a spec's
  R6 text described a `:rawPredict` path joined after the prefix;
- `ApigeeModel::google_variant()` is `None` (the `Llm` default): Go's `apigeeModel` is not a
  `model.GoogleLLM` (the 3a spec's R15 said it delegates);
- the 10-minute response-header timeout applies only to the default client of the Anthropic
  backend, as Go's `defaultAnthropicHTTPClient` does; the Vertex default client has none;
- tests never depend on a developer's Application Default Credentials: Go subtests that need
  "no ADC" point `GOOGLE_APPLICATION_CREDENTIALS` at a missing file instead, and
  `TestSamplePNG1x1_DecodesAsValidPNG` checks the PNG signature, IHDR and CRCs by hand (no PNG
  decoder dependency);
- an ADC token failure on Vertex (Application Default Credentials that cannot produce a token
  when a request is sent) is a transport error whose detail is google-cloud-auth's error text,
  not Go `oauth2`'s (explicit `credentials` have no Go `oauth2` counterpart).
