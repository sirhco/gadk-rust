`artifact/gcsartifact/gcs_client_test.go` →
`crates/gadk-artifact-gcs/src/parity_tests/artifact_gcsartifact_gcs_client.rs` (both reach the
crate-private bucket seam: the in-memory fake, and the REST client against a 127.0.0.1 fake
server). The 2 files hold 16 `Test*` functions.

Accepted divergences (each annotated where it lives):
- a missing artifact is `ArtifactError::NotFound` (`artifact not found: file does not exist`),
  where Go's `Load`/`GetArtifactVersion` say `artifact '{blob}' not found: file does not exist`;
- every upload is one multipart request (Go switches to a resumable upload above 16 MiB);
- the JSON API only (Go reads object bytes through the XML API and can use gRPC): gRPC
  `FailedPrecondition` detection has no counterpart;
- transport retries are bounded (3 retries for listing, metadata, reads and uploads; none for
  deletes) where Go's storage client retries idempotent calls until the context ends; the
  transport also retries 409 and honours `x-should-retry`;
- `GcsConfig::endpoint` is a base URL (host, optionally ending `/storage/v1`); other paths are
  rejected, where Go accepts any endpoint path;
- cancellation is dropping the future: Go `sleepContext`'s `context.Canceled` and an injected
  `context.Canceled` delete error have no counterpart;
- an inline part with an empty MIME type is uploaded as `application/octet-stream` with no
  `contentType` in the object metadata, where Go's writer sniffs a content type;
- `googleapi` error text is `googleapi: Error {status}: {message}` (or `googleapi: got HTTP
  response code {status} with body: {body}`) without Go's `, {reason}` / details suffixes.
