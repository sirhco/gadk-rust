# Parity ledger — sub-project 6c-2

ADK-Go commit: see `docs/parity/ADK_GO_COMMIT`. Test-name rule: see the 1b spec § Parity tooling.

Rows below the table header are generated by `python3 scripts/parity-check --ledger 6c-2 --generate`
from annotations in each Go test file's Rust target. Do not edit rows by hand:
- `fn test_foo` in the target → `ported`; a `// parity: adapted: <reason>` line within the 3
  lines above the `fn` → `ported (adapted: <reason>)`;
- a line `// parity: skipped TestFoo: <reason>` in the target → `skipped`.

Scope: ADK-Go's `internal/configurable` (`configurable.go`, `configurable_utils.go`,
`configurable_workflow.go`: the YAML agent/tool/callback/node-function registries, the five agent
classes, the eight built-in tool and toolset factories, workflow graphs), its conformance package
`internal/configurable/conformance` (`loader.go`, `callbacks.go`, `functions.go`, `nodes.go`), the
record and replay plugins (`recordplugin/`, `replayplugin/` with `recording/recording.go`) and
`cmd/internal/adkcli`, ported to the internal crate `crates/gadk-configurable` (`publish = false`;
no crate depends on it, the `gadk` façade never re-exports it) with its binary `adkcli`. All
targets live in `crates/gadk-configurable/src/parity_tests/internal_configurable_<path>.rs`. The
crate's own tests have no rows: unit tests per module, `tests/recordings_differential.rs`
(44 Go-recorded cases: record bytes, replay decoding, round trip, and the type-path fixup table
against the probe's reflection-generated one; written by `scripts/gen-go-configurable`),
`tests/plugins_integration.rs` (both plugins under a runner, against Go-written goldens) and
`tests/adkcli.rs` (stdout, stderr and exit codes captured from Go's `adkcli`, REST-mode replay).

Out of scope (not ported):
- installing or publishing `adkcli`, and re-exporting anything from the `gadk` façade;
- non-Gemini models and inline `code` agent references in YAML configs (Go rejects both too);
- running the external (adk-python) conformance harness;
- go-cmp's diff text inside replay mismatch errors (a divergence, below);
- changes to gadk-genai's serde shape.

Follow-ups outside this crate (found here, not divergences of 6c-2's code):
- gadk-goyaml type-error type names (ledger 6c-1 naming) surface in this crate's texts: a Go
  `int`/`uint` field (`max_iterations`, `max_concurrency`, `user_message_index`) is named
  `int64`/`uint64` (Go: `into int` / `into uint`); a sequence field is `[]interface {}` (Go:
  `[]configurable.agentRefConfig`, `[]yaml.Node`); errors inside gadk-genai types name gadk's serde
  struct names, and a gadk serde custom error (a non-duration string at a `Duration`, a date
  mapping without `year`) aborts with serde's text instead of yaml.v3's type error. A gadk-goyaml
  change (sequence names from the element's serde name, Go width names) would fix most of them.
  The `agents.rs` tests pin the current texts with `Divergence candidate (ledger 6c-2)` notes
  (`[]interface {}`, `uint64`); they are this follow-up, not 6c-2 divergences.
- gadk-server: `RetriableRunner::validate_compaction` calls `Loader::root_agent()` eagerly per
  trigger request, so `adkcli web pubsub|eventarc` with every `root_agent.yaml` failing to load
  panics in the request task (the conformance loader's empty-map panic, below); Go reaches
  `LoadAgent` and answers with the loader's not-found error. The fix belongs in gadk-server (a
  placeholder agent, as `rest/mod.rs` does).

Accepted divergences (each annotated `// Divergence (ledger 6c-2)` where it lives; 31):

Agents, tools and workflows:
- `LoopAgent` `max_iterations` (Go `uint`, 64-bit) saturates at `u32::MAX` (gadk-engine's field is a `u32`; Go never errors on it) — `crates/gadk-configurable/src/agents.rs` (`to_loop_agent_config`).
- `ExampleTool` examples are decoded with gadk-genai's serde: keys match exactly (Go's `encoding/json` also accepts case-insensitive keys) and a type error carries serde_json's text after `failed to decode normalized examples: ` — `crates/gadk-configurable/src/builtin_tools.rs` (`decode_examples`).
- `ExampleTool`: a `null` example or `null` output element (Go: a nil pointer that panics later in `buildExamplesSystemInstruction`) becomes an empty example / content — `crates/gadk-configurable/src/builtin_tools.rs` (`decode_examples`).
- A non-UTF-8 Go string (only from `!!binary`) in `config_path`, `func`, `command`, `server_params.args` or `tool_filter` is used with U+FFFD per invalid byte; Go passes the raw bytes on — `crates/gadk-configurable/src/builtin_tools.rs` (`go_string`).
- `castNodeFunction`'s `fmt.Sprint`: node inputs are JSON values, so a number prints as a Go `float64` (`1e+06`) where Go's producer may have returned an `int` (`1000000`) — `crates/gadk-configurable/src/workflow.rs` (`cast_node_function`).
- `ConformanceAgentLoader::root_agent` on an empty loader panics (gadk's `Loader::root_agent` has no nil); Go returns nil, which `runner.New` rejects (`root agent is required`) or a caller dereferences. `adkcli` keeps the console path Go-identical (below); `adkcli web … a2a` with every config failing panics in the loader (exit 101) where Go panics on the nil agent (exit 2) — `crates/gadk-configurable/src/conformance/loader.rs` (`root_agent`).

adkcli:
- With every `root_agent.yaml` failing, the console is wrapped in `NilRootConsole`, which fails with Go's `failed to create runner: root agent is required` before initializing telemetry (`-otel_to_cloud`) and creating the session, as Go's console does first; a telemetry-init failure Go would report instead is not reported — `crates/gadk-configurable/src/bin/adkcli.rs` (`NilRootConsole`).
- A directory read failing after a successful open is a `readdirent <path>: …` path error; Go's op name there is platform-specific (only the `open` failure is verified byte-identical, and it is unreachable in practice) — `crates/gadk-configurable/src/bin/adkcli.rs` (`read_dir_error`).

Record plugin and Go-shaped encoding:
- `user_message_index` as a float outside `int` range saturates (Go's `int(float64)` is platform-defined: arm64 saturates, amd64 gives `math.MinInt64`); a JSON integer above `i64::MAX` takes the same path — `crates/gadk-configurable/src/conformance/record/mod.rs` (`parse_record_config`).
- Recorded requests and responses are snapshots taken in the callbacks; Go keeps a shallow request copy (sharing `Contents`/`Config`) and the response pointer, so a later mutation before `afterRun` would show in Go's file (no known Go path makes one) — `crates/gadk-configurable/src/conformance/record/mod.rs` (`before_model`).
- `cleanYAMLNode` walks an explicit stack (same visiting and mutation order) instead of recursing, so arbitrarily deep input cannot overflow the stack; output is identical — `crates/gadk-configurable/src/conformance/record/clean.rs` (`clean_yaml_node`).
- `toCamelCaseTitle` upper-cases the first byte as Go does; for a non-ASCII first character Go's string is invalid UTF-8 (`yaml.Marshal` then fails and no file is written), while Rust replaces each orphaned byte with U+FFFD and writes the file — `crates/gadk-configurable/src/conformance/record/clean.rs` (`to_camel_case_title`).
- The base-directory check's `invalid path format: %v` for a failed `os.Getwd` (inside `filepath.Abs`) prints the bare errno text; Go's may carry an op prefix (only when the working directory is gone). Shared by both plugins — `crates/gadk-configurable/src/lib.rs` (`check_within_base_dir`).
- A non-UTC `time.Time` (`timeRangeFilter`) encodes with `Z` (gadk stores `DateTime<Utc>`); Go keeps the source offset (same instant) — `crates/gadk-configurable/src/conformance/gonode/fixups.rs` (`field_node`).
- A JSON schema decoded from a recording is re-encoded reshaped as a `*jsonschema.Schema`; Go re-encodes its decoded `map[string]any` as is (reachable only through the merge path re-reading a file written with Go-default keys) — `crates/gadk-configurable/src/conformance/gonode/fixups.rs` (`field_node`).
- jsonschema `default` (`json.RawMessage`) is Go `json.Marshal` of the value, equal to Go's raw source bytes only for a compact, sorted-key, HTML-escaped source (as every probe and `jsonschema.For` source is) — `crates/gadk-configurable/src/conformance/gonode/jsonschema.rs` (`reshape`).
- Recordings nested deeper than 127 collections (recursive `genai.Schema` / `jsonschema.Schema` values) fail with gadk-goyaml's `yaml: exceeded max depth of 127` in the type-path fixups' encode and decode walks; Go's `node.Encode` / `node.Decode` have no cap (growable goroutine stacks) — `crates/gadk-configurable/src/conformance/gonode/fixups.rs` (`MAX_WALK_DEPTH`).
- An alias at a `[]byte`, `civil.Date` or `time.Time` position is not followed by the inverse fixups (yaml.v3 decodes its target); Go-written files contain no aliases — `crates/gadk-configurable/src/conformance/gonode/fixups.rs` (`bytes`).
- A `civil.Date` `UnmarshalText` failure while decoding returns `Err` with no value; yaml.v3 aborts but leaves what it filled, which the merge path would keep (reachable only with Go-default keys) — `crates/gadk-configurable/src/conformance/gonode/mod.rs` (`from_go_node_partial`).
- A nil `*model.LLMResponse` element (`llm_responses: [null]`) cannot be represented in `Vec<LlmResponse>` — `crates/gadk-configurable/src/conformance/gonode/roots.rs` (`LlmRecordingDe`).

Replay plugin:
- `normalizeYAMLNode` on a hand-built mapping with an odd number of children leaves the dangling key (Go panics indexing `Content[i+1]`; parsed documents cannot produce it) — `crates/gadk-configurable/src/conformance/replay/normalize.rs` (`normalize_yaml_node`).
- `HTTPOptions`: Go compares the live `Config.HTTPOptions` against the recorded nil; gadk keeps HTTP options on `LlmRequest.http_options` and ignores them — `crates/gadk-configurable/src/conformance/replay/matching.rs` (`RequestFields`).
- Go's `verifyLLMRequestMatch` normalizes both requests in place (descriptions, the forced `transfer_to_agent` text, canonicalized text parts stay on the live request); gadk compares copies and leaves the live request untouched — `crates/gadk-configurable/src/conformance/replay/matching.rs` (`verify_llm_request_match`).
- JSON-substring canonicalization: serde_json refuses nesting deeper than 128 levels (Go allows 10000), so such text stays as it is (the workspace's deep-JSON policy) — `crates/gadk-configurable/src/conformance/replay/matching.rs` (`go_json_round_trip`).
- Tool args: gadk's live args are never Go's nil map, so recorded `nil` args always mismatch (Go: equal to a nil live map); Go-written recordings always carry `args: {}` — `crates/gadk-configurable/src/conformance/replay/matching.rs` (`verify_tool_call_match`).
- Mismatch error bodies (spec R14): Go's prefix text is kept, the body is a gadk field-path diff (`-<path>: <expected>` / `+<path>: <actual>` per differing leaf) instead of go-cmp's report — `crates/gadk-configurable/src/conformance/replay/matching.rs` (`request_diff`).
- A recording without `tool_response` (Go: nil dereference, panic) is treated as a nil response map (no override; the real tool runs) — `crates/gadk-configurable/src/conformance/replay/mod.rs` (`before_tool`).
- A recorded tool response value JSON cannot hold (see `go_map_to_json`) is an error; Go hands its `map[string]any` back as is (unreachable from Go-written recordings) — `crates/gadk-configurable/src/conformance/replay/mod.rs` (`before_tool`).
- `user_message_index`: any JSON number is accepted (integers as is, others truncated, out-of-range floats saturate); Go accepts exactly `int` or `float64` (an `int64` only Go code could store is rejected) — `crates/gadk-configurable/src/conformance/replay/mod.rs` (`load_invocation_state`).
- A recording without `llm_request` (Go: nil dereference, panic) is compared against an empty request (a mismatch error) — `crates/gadk-configurable/src/conformance/replay/mod.rs` (`verify_and_get_next_llm_recording_for_agent`).
- A tool recording without `tool_call` (Go: nil dereference, panic) is compared against an empty call (a tool-name mismatch) — `crates/gadk-configurable/src/conformance/replay/mod.rs` (`verify_and_get_next_tool_recording_for_agent`).

Not annotated (no Go-observable effect, or not applicable):
- Go log timestamp prefixes on stderr (anticipated by spec R14): `gadk_launcher::golog` writes Go's `log` prefix format, so only the time value differs from run to run (the tests mask it); no divergence.
- `jsonschema.Schema.PropertyOrder` (set by `jsonschema.For`) is not representable from JSON, so the pre-clean node has `propertyorder: []`; cleaning always prunes it outside tool args, so the bytes are equal (44/44 goldens).
- Go's `Node.Content` nil-vs-empty distinction (ledger 6c-1) is invisible in the record output.
- Go's unsynchronized `invocationStates` read in the replay plugin's `getInvocationState` (a Go data race) is a locked read.
- N/A: `ctx.Session() == nil`, `sessionState == nil` and `resp == nil` guards (a gadk invocation always has a session and state; the after-model callback always gets a response); Go `init()` / `RegisterNodeFunction` bad-signature panics (typed API; `Registry::new()` is infallible); `ResolveToolReference`'s `is not a tool or toolset factory` (typed `ToolEntry`); `functiontool.New` failures for the fixed conformance types (kept, unreachable); `record.New` / `replay.New` always-nil errors (they return the `Plugin`); `log.Fatalf("Error walking the path")` (unreachable in Go too); `uppercase_formatter` inputs other than JSON values (every gadk node input is JSON).
- N/A: non-UTF-8 paths and arguments are handled lossily (`to_string_lossy`); non-Unix platforms: `go_getwd` never trusts `$PWD`, `os.WriteFile`'s mode applies only on Unix, `tests/adkcli.rs` is Unix-only.
- Faithful but surprising Go behavior kept: the workflow node cache is registry-wide and never invalidated; the record plugin keeps one pending LLM request per invocation (parallel agents' concurrent calls overwrite each other); a tool recording reached from an LLM call waits forever in replay (as in Go).
