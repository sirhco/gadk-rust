# Parity ledger — sub-project 2b

ADK-Go commit: see `docs/parity/ADK_GO_COMMIT`. Test-name rule: see the 1b spec § Parity tooling.

Rows below the table header are generated by `python3 scripts/parity-check --ledger 2b --generate`
from annotations in each Go test file's Rust target (`crates/*/tests/<target>.rs` or
`crates/*/src/parity_tests/<target>.rs`, where `<target>` is the Go path without `_test.go`, with `/`
replaced by `_`). Do not edit rows by hand:
- `fn test_foo` (or, for a Go `FuzzFoo`, `fn fuzz_foo`) in the target → `ported`; a
  `// parity: adapted: <reason>` line within the 3 lines above the `fn` → `ported (adapted: <reason>)`;
- a line `// parity: skipped TestFoo: <reason>` in the target → `skipped`.

Go files in package `auth` or `gcp` (internal tests) have `#[cfg(test)]` targets under
`crates/gadk-auth/src/parity_tests/`; files in package `auth_test` or `gcp_test` have targets under
`crates/gadk-auth/tests/`, and `tool/toolauth` (package `toolauth_test`) under
`crates/gadk-tools/tests/`. The gcp targets build only with the `gadk-auth` feature `gcp` (on by
default). `auth/gcp/redact_fuzz_test.go` `FuzzRedact` is ported as the deterministic
`fn fuzz_redact` (the Go seed corpus plus 10,000 xorshift64 inputs).

Accepted divergences (no Go test asserts them):
- header names are lowercase on the wire (`http::HeaderName`), where Go canonicalizes them;
- `tracing` event text replaces Go's `log`/`slog` lines;
- a non-UTF-8 credential-service body is decoded lossily before redaction, so an error shows U+FFFD
  where Go's `%q` shows `\x80`.
